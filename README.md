# Profil Diri Saya

Halaman web profil diri sederhana berbasis HTML & CSS, dibuat oleh **Kristian Natalis** (255314019) — mahasiswa Program Studi Informatika, Fakultas Sains dan Teknologi, Universitas Sanata Dharma, Yogyakarta.

## Isi Halaman

- **Profil Saya** — foto profil dan tabel data diri (nama, asal, program studi, universitas, tanggal & tempat lahir)
- **Tentang** — deskripsi singkat diri dan tujuan hidup
- **Hobi** — daftar hobi dan minat
- **Kemampuan** — daftar skill yang dimiliki
- **Portofolio** — tautan ke GitHub
- **Kontak** — email, Instagram, dan Discord

## Struktur File

## Cara Menjalankan

Cukup buka file `profil.html` di browser mana pun — tidak perlu server atau instalasi tambahan.

> Pastikan file `foto.png` berada di folder yang sama dengan `profil.html` agar foto profil tampil.
